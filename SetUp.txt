Create the maps through unity (using the grid snapping option will make it faster)

For each level, we can copy Level1Scene, then in 
	Level initializer, put the tiles of the map and the player cube there

Add the player cube to the levelmanager and the name of the next level scene

To set the player initial position, its also better to use the grid snapping, same for the
victory hole etc
----------------------------------------
LevelInitializer currently is used to set the animation when starting a level of all tiles at once,
instead of running a script for each tile
